# bakshu-vibe

מערכת נוכחות, ניקוד ולוח מבצע - ישיבת בקשו ירושלים.

## תיאור המערכת
מערכת מודרנית לניהול נוכחות סדרים ותפילות, ניקוד אישי וקבוצתי, לוח מבצע חורף, סינכרון יומן (iCal) וממשק ניהול עבור אחראי המבצע.

## מבנה הפרויקט
- `index.html`: הממשק הראשי (Dashboard + Mobile view)
- סכמת מסד נתונים Supabase מותאמת באזור `eu-central-1` (Frankfurt)
- חיבור ופריסה ב-Vercel

## פריסה (Deployment)
הפרויקט מחובר לפריסה אוטומטית ב-Vercel ומקושר למאגר GitHub `bakshu-vibe`.
